# 🖼️ CAPTION: Arian Prabowo's Translation of Images into Optimized Narratives

An AI Agent Skill designed to translate visual assets (images, figures, tables, animations, or generation code) into optimized, domain-specific text anchors. It enforces standalone comprehension, maximal information density, and zero redundancy.

by www.arianprabowo.com

## Overview

All figures and visual artifacts are making an argument. The **CAPTION** skill ensures that this argument is explicitly stated in the caption text. It extracts novel, exciting, unexpected, surprising, and salient features from the image and formats them according to the strict syntactical rules of the target publication domain.

## Universal Invariant Laws

All generated captions strictly adhere to three non-negotiable laws:
1. **Standalone Comprehension**: A figure and its caption form a closed, autonomous epistemological loop. No reliance on external body text.
2. **Cognitive Proximity (Spatial Contiguity)**: The text must live in the immediate spatial vicinity of the visual artifact.
3. **Redundancy Elimination**: No description of obvious visual elements (e.g., "This is a bar chart showing..."). No echoing of the main text.

## Domain-Specific Optimizations

The skill dynamically adjusts its syntax, tense, and data density based on the target domain:

* **Academic & STEM**: Focuses on methodological reproducibility. Uses declarative hooks, exact p-values, n-values, and strict error bar definitions.
* **Journalistic & Editorial**: Focuses on temporal precision. Employs the AP Formula (Subject, Action, Context) and strict attribution formatting.
* **Technical & Accessibility**: Focuses on algorithmic parsing and guided action. Uses imperative verbs and separates human-readable action from machine-readable state (alt-text).
* **Textbooks & Pedagogy**: Focuses on cognitive scaffolding. Uses progressive disclosure and eliminates seductive details to protect working memory.
* **Blogs & Digital Media**: Focuses on SEO indexing and scannability. Employs bold front-loaded hooks, kebab-case filenames, and F-pattern interception.
* **Business & Corporate**: Focuses on Executive ROI. Uses the Executive Hook (actionable financial delta first) and bypasses chart description entirely to dictate operational next steps.

## Usage

This skill is designed for Antigravity / Gemini CLI and adheres to [Agent Skills Best Practices](https://agentskills.io). To use it, simply invoke the skill when you need an insightful, domain-optimized caption for a visual asset.
